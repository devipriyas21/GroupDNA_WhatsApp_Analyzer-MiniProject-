# GroupDNA - WhatsApp Group Analyzer

A Python-based WhatsApp chat analyzer that extracts useful insights from exported group chats.

## Features

- Chat parsing
- Group overview
- Most active day and hour
- Activity heatmap using NumPy
- Top words analysis
- Response time analysis
- Personality archetypes
- Final analytical report

## Technologies Used

- Python
- NumPy
- Datetime

## How to Run

1. Open the notebook in Google Colab or Jupyter Notebook.
2. Place the exported WhatsApp chat file (`hostel_bois.txt`) in the same folder.
3. Run all cells from top to bottom.

## Output

The notebook generates:

- Group statistics
- Activity heatmap
- Favourite words
- Response analysis
- Personality archetypes
- Final report
